# FEEDS — DUAT inputs

Public / developer feeds only. Same honesty model as God's Eye View.

| Layer | Source | Auth |
|---|---|---|
| Flights | OpenSky, adsb.lol | anon or free key |
| Military ADS-B (public) | adsb.lol | none |
| Vessels | AISStream | free key |
| Sats | CelesTrak / TLE | none |
| Quakes | USGS | none |
| Fires | NASA FIRMS | free map key |
| Map tiles | OSM / optional Google 3D | Google is metered |
| Globe UI pattern | [gods-eye-view](https://github.com/bilawalsidhu/gods-eye-view) | MIT globe, their keys stay theirs |

Instagram reel `Dc8Q_Zmq11I` was requested as a visual reference. This environment cannot fetch Instagram (429). Drop a screenshot or caption into an issue if you want that look copied into HORUS Eye.

## Rule

Delayed data is labeled delayed. Simulated traffic is labeled simulated. Reconstructed launch paths are labeled reconstructed. No theater without the stamp.
